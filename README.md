# Portfolio — Riccardo Lotronto

Personal portfolio site for a Cloud / DevOps Engineer. Built with React, Vite and Tailwind CSS, with an animated particle background and bilingual content (IT / EN).

**Live:** https://nexusites.github.io

## Tech Stack

React 18, Vite 5, Tailwind CSS 3, Framer Motion, vanilla Canvas particle background.

## Develop

```bash
npm install
npm run dev      # local dev server
npm run build    # production build into dist/
```

## Deploy

This repo auto-deploys to GitHub Pages via GitHub Actions on every push to main
(see .github/workflows/deploy.yml). In the repo settings, set Pages source to
"GitHub Actions".
